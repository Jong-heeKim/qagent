# 고객 체험 일지

> 대상: AI Agent의 품질 측정이 필요한 사용자  
> 목적: 현재 환경에서의 고객 행동, 인식, 감정 반응 및 불편 사항 분석을 통한 현재 문제와 잠재 니즈 발굴  
> 고객경험 단계: 품질문제 인식 → 측정방법 탐색 → 평가환경 구성 → 측정 실행 → 결과 분석 → 개선 적용

| 측정방법 탐색 | GitHub, Reddit, 유튜브를 3일간 탐색. DeepEval, RAGAS, LangSmith를 비교했지만 차이를 이해하기 어려움 | 3일 | Google 검색, GitHub | 도구가 너무 많아서 오히려 더 헷갈림. 비교표라도 있었으면 좋겠다 |
| 평가환경 구성 | DeepEval 설치 후 테스트셋 수동 작성. 100개 케이스 만드는 데 이틀 소요. 어느 정도 분량이 적절한지 기준 없음 | 2일 | Python, DeepEval | 테스트셋 만드는 것 자체가 일이 될 줄 몰랐음 |

| 개선 적용 | 청크 사이즈·프롬프트·검색 파라미터 3가지를 동시에 변경하여 재실험. 어떤 변수가 효과 있었는지 분리 불가 | 2일 | Python | 실험하는 건 좋은데 원인을 모르면 실험이 쌓이지 않음 |
