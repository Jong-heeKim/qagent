| 품질문제 인식 | 고객 컴플레인 로그를 수동으로 훑어보며 Agent 오답 케이스를 직접 수집 | "Agent가 잘못 답변하는 것 같은데 얼마나 자주인지 모르겠다" | 불안, 답답함 | 문제 발생 시점을 실시간으로 알 수 없음 |
| 측정방법 탐색 | GitHub에서 "LLM evaluation framework" 검색, DeepEval·RAGAS 문서 탐색 | "뭐가 맞는 도구인지 너무 많아서 고르기 어렵다" | 혼란, 시간 낭비 | 도구별 비교 기준이 없어 선택 근거 없음 |

| 측정 실행 | 터미널에서 CLI로 평가 스크립트 실행, 결과 JSON 파일 수동 확인 | "돌려놓고 기다리는 것 외에 할 수 있는 게 없다" | 무기력, 지루함 | 실행 중 오류 발생 시 원인 파악이 어려움 |

| 개선 적용 | 프롬프트 수정 후 재실행, 개선 여부를 눈으로 비교 | "개선됐는지 확인하는 기준이 없다" | 피로, 반복적 허탈감 | 개선 이력 추적 수단 없음 |
