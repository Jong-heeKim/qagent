# AI Agent 품질 측정 플랫폼 - 유저스토리

## 마이크로서비스 구성
1. **User** - 사용자 인증 및 계정 관리
2. **Agent** (AGNT) - AI 에이전트 등록 및 연결 관리
3. **Eval** (EVAL) - 품질 평가 실행 및 결과 관리
4. **Monitor** (MNTR) - 이상 감지 및 알림
5. **Report** (REPT) - 주간 브리핑 자동 발송
6. **Gate** (GATE) - CI/CD 품질 게이트
7. **Widget** (WDGT) - 품질 위젯 공유

  [처리 결과]
  - 성공: 에이전트 ID와 설정 요약 표시

3. Eval 서비스
1) 테스트셋 관리
UFR-EVAL-010: [테스트셋업로드] AI품질엔지니어로서 | 나는 AI 에이전트를 평가하기 위해 | CSV/JSON/YAML 형식의 테스트케이스 파일을 업로드하고 싶다.
- 시나리오: 테스트셋 업로드 및 검증
  로그인한 상태에서 테스트셋 업로드 화면에 접근한 상황에서 | 파일(CSV/JSON/YAML)을 선택하고 업로드 버튼을 클릭하면 | 필수 컬럼(question/answer/context) 검증을 통과한 후 테스트셋 ID와 케이스 수가 표시된다.

  [형식 검증]
  - 지원 형식: CSV, JSON, YAML
  - 필수 컬럼: question(질문), answer(정답), context(컨텍스트)
  - 최대 파일 크기: 10MB
  - 케이스 수 제한: 최대 1,000건

  [검증 결과]
  - 성공: 테스트셋 ID, 파일명, 케이스 수, 업로드 일시 표시
  - 실패: 누락 컬럼명, 형식 오류 위치를 구체적으로 안내

  [체크리스트]
  - [ ] CSV/JSON/YAML 3가지 형식 모두 업로드 가능
  - [ ] 필수 컬럼 누락 시 구체적 오류 메시지 표시
  - [ ] 업로드 후 객체 스토리지 저장 및 경로 반환 확인
  - [ ] 테스트셋 ID 자동 생성 확인

2) 품질 평가 실행
UFR-EVAL-020: [평가실행] AI품질엔지니어로서 | 나는 AI 에이전트의 품질 수준을 정량적으로 측정하기 위해 | 테스트셋과 평가 지표를 선택하여 LLM-as-Judge 평가를 실행하고 싶다.
- 시나리오: 품질 평가 실행 (전체 모드)
  테스트셋이 업로드된 상태에서 평가 실행 화면에서 | 에이전트, 테스트셋, 평가 지표(Faithfulness/AnswerRelevancy/ContextRecall), 평가 모드(전체/경량)를 선택하고 실행하면 | 각 테스트케이스에 대해 AI 응답이 생성되고 LLM-as-Judge로 지표가 산출된다.

  [평가 모드]
  - 전체 모드: 테스트셋 전체 케이스 평가
  - 경량 모드: 핵심 케이스 50건만 평가 (비용/속도 최적화)

  [지표 산출]
  - Faithfulness: AI 응답이 컨텍스트에 근거한 정도
  - AnswerRelevancy: 질문에 대한 응답의 관련성
  - ContextRecall: 정답 내용의 컨텍스트 포함 여부

  [이상 감지 연계]
  - 임계값 위반 지표 존재 시 → Monitor 서비스 이상 감지 알림(UF03) 자동 트리거
  - 전일 대비 10% 이상 하락 시 → 경고 플래그 부여

  [체크리스트]
  - [ ] 전체/경량 모드 선택 기능 동작 확인
  - [ ] 평가 진행 중 프로그레스 표시
  - [ ] 각 케이스별 AI 응답 및 지표 점수 저장 확인
  - [ ] 평가 완료 후 결과 조회 화면 자동 이동 또는 링크 제공
  - [ ] 임계값 위반 시 Monitor 서비스 트리거 확인

- M/34

UFR-EVAL-030: [결과조회] AI품질엔지니어로서 | 나는 평가 결과를 분석하여 개선 방향을 도출하기 위해 | 지표별 점수, 추이 그래프, 위반 내역을 한눈에 조회하고 싶다.
- 시나리오: 평가 결과 상세 조회
  평가가 완료된 상태에서 결과 조회 화면에 접근한 상황에서 | 평가 ID로 결과를 조회하면 | Faithfulness/AnswerRelevancy/ContextRecall 점수, 전일 대비 변화율, 추이 그래프, 위반 지표 목록이 표시된다.

  [표시 항목]
  - 지표별 점수 (0.00~1.00)
  - 전일 대비 변화율 (상승↑/하락↓)
  - 이전 평가와 비교 그래프
  - 임계값 위반 지표 목록 (위반 값 및 기준값 표시)
  - 경고 플래그 (10% 이상 하락 시 표시)

  [체크리스트]
  - [ ] 지표별 점수 소수점 2자리 표시
  - [ ] 변화율 양수(+)/음수(-) 색상 구분
  - [ ] 추이 그래프 최근 10회 평가 이력 표시
  - [ ] 위반 지표 강조 표시 (빨간색 테두리 등)
