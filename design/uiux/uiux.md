## 2. 사용자 플로우

### 2.1 신규 사용자 온보딩 플로우

```
02-회원가입 → 01-로그인 → 03-메인대시보드
  → "에이전트 등록" 유도 배너 클릭
  → 05-에이전트등록 (Step1 기본정보 → Step2 연결테스트 → Step3 완료)
  → 06-에이전트상세설정 (임계값 / 알림채널)
  → 07-테스트셋관리 (파일 업로드)
  → 08-평가실행 → 09-평가결과
```

### 2.2 ML엔지니어 반복 사용 플로우

```
01-로그인 → 03-메인대시보드
  → 08-평가실행 → 09-평가결과
  → 11-알림이력 (이상 알림 확인)
  → 15-게이트결과 (PR 게이트 차단 원인 분석)
```

### 2.3 PM·기획자 플로우

```
01-로그인 → 03-메인대시보드 (신호등 현황 확인)
  → 16-위젯설정 → 공유 URL 생성 → 경영진에게 전달
  → 12-브리핑설정 (Slack/이메일 수신 설정)
  → 13-브리핑이력 (과거 브리핑 확인)
```

### 2.4 경영진·파트너 플로우 (비인증)

```
공유 URL 수신 → 17-위젯공개조회
  유효 URL → 신호등 + 업계 상위 N% + 회원가입 CTA
  만료 URL → 만료 안내 화면
```

### 2.5 개발자 CI/CD 플로우

```
01-로그인 → 14-게이트설정 (YAML 설정 + 웹훅 URL 획득)
  → CI/CD 파이프라인 웹훅 연동 (외부 작업)
  → PR 생성 시 자동 게이트 실행 (UFR-GATE-020, UI 없음)
  → 차단 알림 수신 → 15-게이트결과 (원인 분석)
```

### 01-로그인

#### 개요
| 항목 | 내용 |
|------|------|
| 목적 | 이메일/비밀번호로 인증하여 JWT 토큰 발급 |
| 관련 유저스토리 | UFR-USER-020 |
| 비즈니스 중요도 | M (필수) |

#### 주요 기능
- 이메일 + 비밀번호 로그인
- 5회 연속 실패 시 30분 계정 잠금 안내
- 토큰 만료 시 자동 로그아웃 및 리다이렉트

#### UI 구성요소
```
[모바일 기본]
┌─────────────────────────────────┐
│         [플랫폼 로고]            │
│      AI Agent 품질 측정 플랫폼   │
│                                  │
│  이메일                          │
│  [이메일 입력 필드]               │
│                                  │
│  비밀번호                         │
│  [비밀번호 입력 필드]  👁         │
│                                  │
│  [로그인 — Primary 버튼 100%]    │
│                                  │
│  계정이 없으신가요? [회원가입]     │
└─────────────────────────────────┘
```
- **로고**: 중앙 상단, 48px 높이
- **이메일 필드**: type=email, placeholder="이메일 주소"
- **비밀번호 필드**: type=password, 우측 눈 아이콘 토글
- **로그인 버튼**: 전체 너비 100%, 높이 52px, Primary 색상
- **오류 메시지**: 필드 하단 빨간 텍스트 12px
- **잠금 안내**: 노랑 배경 인라인 경고 박스

#### 인터랙션
- Enter 키로 로그인 실행
- 로그인 중 버튼 비활성화 + 로딩 스피너
- 성공 → 03-메인대시보드 이동
- 실패 → 구체적 오류 메시지 인라인 표시

### 02-회원가입

#### 개요
| 항목 | 내용 |
|------|------|
| 목적 | 신규 계정 생성 및 역할 설정 |
| 관련 유저스토리 | UFR-USER-010 |
| 비즈니스 중요도 | M (필수) |

#### 주요 기능
- 이름/이메일/비밀번호/역할 입력 및 실시간 유효성 검사
- 이메일 중복 확인 (비동기)
- 비밀번호 강도 표시

#### UI 구성요소
```
[모바일 기본]
┌─────────────────────────────────┐
│         [플랫폼 로고]            │
│                                  │
│  이름    [입력 필드]              │
│  이메일  [입력 필드]  ✓/✗        │
│  비밀번호 [입력 필드]             │
│  [▓▓▓▓░░░] 보통                 │  ← 비밀번호 강도 바
│  역할    [드롭다운 ▼]            │
│                                  │
│  [가입하기 — Primary 버튼 100%]  │
│  이미 계정이 있으신가요? [로그인] │
└─────────────────────────────────┘
```
- **이름 필드**: 2자 이상 실시간 검증
- **이메일 필드**: 포커스 아웃 시 중복 확인 API (500ms 디바운스), ✓ 사용 가능 / ✗ 이미 사용 중
- **비밀번호 강도 바**: 4단계 색상 바 (약함→빨강 / 보통→노랑 / 강함→초록 / 매우강함→파랑)
- **역할 드롭다운**: ML엔지니어 / AI품질엔지니어 / PM·기획자 / 개발자
- **가입하기 버튼**: 모든 필드 유효 시 활성화

#### 인터랙션
- 이메일 포커스 아웃 → 비동기 중복 확인
- 가입 성공 → "회원가입이 완료되었습니다" 토스트 → 01-로그인 이동

### 03-메인대시보드

#### 개요
| 항목 | 내용 |
|------|------|
| 목적 | 등록된 에이전트 품질 현황 한눈에 파악 및 빠른 액션 |
| 관련 유저스토리 | UFR-AGNT-050, UFR-EVAL-030, UFR-MNTR-020 |
| 비즈니스 중요도 | M (핵심 진입점) |

#### 주요 기능
- 에이전트별 신호등 현황 카드 목록
- 이상 감지 알림 배너 (임계값 위반 시 상단 고정)
- 빠른 액션 (평가 실행, 에이전트 등록)
- 최근 평가 이력 요약 (최근 3건)

#### UI 구성요소

**모바일 기본 레이아웃**:
```
┌────────────────────────┐
│ ⚠ [이상 감지 배너]      │  ← 위반 시만 표시 (빨강/노랑)
├────────────────────────┤
│ 안녕하세요, 홍길동님     │
│ 등록 에이전트 3개        │
├────────────────────────┤
│ [+ 평가 실행] [+ 에이전트 등록] │  ← 빠른 액션
├────────────────────────┤
│ 에이전트 현황           │
│ ┌──────────────────┐  │
│ │ ● 정상  챗봇-A    │  │
│ │ 마지막 평가: 2시간 전 │  │
│ │ 정확도 업계 상위 72% │  │  ← 비기술 언어
│ └──────────────────┘  │
│ ┌──────────────────┐  │
│ │ ● 경고  RAG-B     │  │
│ │ 마지막 평가: 1일 전  │  │
│ └──────────────────┘  │
├────────────────────────┤
│ 최근 평가 이력 (3건)    │
│ • 챗봇-A  어제 14:30   │
│ • RAG-B   어제 09:00   │
├────────────────────────┤
│ 🏠  🤖  📊  ⚙️         │  ← Bottom Nav 4탭
└────────────────────────┘
```

**데스크탑 확장**:
- 좌측 240px 사이드바 고정
- 에이전트 카드 2-3열 그리드
- 상단 이상 감지 배너 (위반 시)

**에이전트 카드 구성**:
- 신호등 원형 아이콘 (24px) + 상태 텍스트 (정상/경고/긴급)
- 에이전트명 (굵게) + 서비스 유형 뱃지
- 마지막 평가 일시 (상대 시간: "2시간 전")
- 업계 상위 N% (업계 비교 활성화 시)
- 호버 시 "평가 실행" 버튼 노출

**이상 감지 배너**:
- 긴급 (빨강 배경): `● 긴급 — [에이전트명] 품질 25% 이상 하락. [대시보드 확인 →]`
- 경고 (노랑 배경): `● 경고 — [에이전트명] 임계값 위반. [확인 →]`
- 닫기(X) 버튼 제공, 상단 sticky

**에이전트 미등록 빈 상태**:
```
┌──────────────────────────────┐
│  🤖                          │
│  아직 등록된 에이전트가 없습니다 │
│  [+ 첫 에이전트 등록하기]       │
└──────────────────────────────┘
```

#### 인터랙션
- 에이전트 카드 클릭 → 06-에이전트상세설정
- "평가 실행" 버튼 → 08-평가실행 (해당 에이전트 선택 상태)
- 이상 감지 배너 링크 → 11-알림이력

### 05-에이전트등록

#### 개요
| 항목 | 내용 |
|------|------|
| 목적 | 신규 AI 에이전트 등록 및 연결 테스트 자동 실행 |
| 관련 유저스토리 | UFR-AGNT-010, UFR-AGNT-020 |
| 비즈니스 중요도 | M (필수) |

#### 주요 기능
- 3단계 위저드: 기본정보 입력 → 연결테스트 → 완료
- API 엔드포인트 연결 테스트 자동 실행 (Step1 완료 즉시)
- 기본 임계값 자동 설정 (Faithfulness/AnswerRelevancy/ContextRecall ≥ 0.7)
- 연결 실패 시 오류 유형 안내 및 수정 유도

#### UI 구성요소 — 3단계 위저드

**단계 표시 (상단 고정)**:
```
① 기본 정보  ───  ② 연결 테스트  ───  ③ 완료
```

**Step 1 — 기본 정보 입력**:
```
┌─────────────────────────────┐
│ 에이전트명 *                 │
│ [텍스트 입력 필드]           │
│                              │
│ 서비스 유형 *                │
│ [드롭다운] RAG / 챗봇 / 검색증강 │
│                              │
│ API 엔드포인트 URL *          │
│ [URL 입력 필드]              │
│ ℹ 내부망 운영 시 플랫폼 IP를  │
│   방화벽 화이트리스트에 등록   │
│                              │
│ API 키 *                     │
│ [비밀번호 스타일 입력]  👁   │
│                              │
│ 모델명 *                     │
│ [텍스트 입력 필드]           │
│                              │
│       [다음 단계 →]          │
└─────────────────────────────┘
```

**Step 2 — 연결 테스트 (자동 실행)**:
```
[성공 상태]
┌─────────────────────────────┐
│  ✅ 연결 성공                │
│  응답시간: 320ms             │
│  상태: 정상                  │
```

## 5. 반응형 설계 전략

### 5.1 Mobile First 브레이크포인트

| 이름 | 범위 | 주요 변화 |
|------|------|----------|
| **Mobile** (기본) | < 768px | Bottom Nav, 1열 카드, 테이블→카드 변환 |
| **Tablet** | 768px ~ 1023px | 64px 아이콘 사이드바, 2열 카드 |
| **Desktop** | ≥ 1024px | 240px 전체 사이드바, 2-3열 카드 |

> **Mobile First CSS 전략**: 모바일 스타일을 기본으로 작성하고 `min-width` 미디어 쿼리로 점진적 확장

```css
/* 기본 (Mobile) */
.agent-grid { grid-template-columns: 1fr; }
.sidebar { display: none; }
.bottom-nav { display: flex; }

/* Tablet */
@media (min-width: 768px) {
  .agent-grid { grid-template-columns: repeat(2, 1fr); }
  .sidebar { display: flex; width: 64px; }
  .bottom-nav { display: none; }
}

/* Desktop */
@media (min-width: 1024px) {
  .agent-grid { grid-template-columns: repeat(3, 1fr); }
  .sidebar { width: 240px; }
}
```

### 5.2 컴포넌트별 반응형 처리

| 컴포넌트 | Mobile | Tablet | Desktop |
|---------|--------|--------|---------|
| 에이전트 카드 | 1열 스크롤 | 2열 그리드 | 3열 그리드 |
| 데이터 테이블 | 카드 형태 변환 | 가로 스크롤 | 전체 표시 |
| 추이 차트 | 가로 스크롤 허용 | 전체 표시 | 전체 표시 |
| YAML 편집기 | 텍스트 뷰+복사 | 에디터 compact | 에디터+가이드 분할 |
| 위저드 스텝 | 숫자만 (①②③) | 숫자+간략 제목 | 전체 텍스트 |
| 위젯 공개 화면 | 1열 세로 중앙 | 1열 중앙 | 1열 중앙 (최대 480px) |

### 5.3 성능 우선 (Mobile First 원칙)

- 이미지: WebP 포맷, `loading="lazy"`, 모바일용 저해상도 우선
- 폰트: 시스템 폰트 폴백 체인 (`'Pretendard', 'Apple SD Gothic Neo', sans-serif`)
- JavaScript: 모바일에서 불필요한 기능(차트 인터랙션) 지연 로딩

## 6. 접근성 보장 방안

### 6.1 색상 독립성 (색맹 대응)

신호등 색상은 반드시 텍스트 또는 아이콘 병행 표시:
- ● 정상 (초록 + 텍스트 "정상")
- ● 경고 (노랑 + 텍스트 "경고")  
- ● 긴급 (빨강 + 텍스트 "긴급")

색상 대비 비율: 최소 WCAG AA 기준 (4.5:1)

### 6.2 키보드 접근성

- 모든 인터랙티브 요소 Tab 키 탐색 가능
- 포커스 링: `2px solid #2563EB`, `outline-offset: 2px`
- 모달: 열릴 때 첫 요소로 포커스 이동, 닫힐 때 트리거 버튼으로 복귀
- ESC 키: 모달/드로어 닫기

### 6.3 스크린 리더

- 아이콘 전용 버튼: `aria-label` 필수
- 동적 콘텐츠: `aria-live="polite"` (평가 진행률, 알림 배너)
- 테이블: `<caption>`, `scope="col"` 적용
- 신호등 원형: `role="img"`, `aria-label="품질 상태: 정상"` 적용

### 6.4 터치 접근성

- 최소 터치 영역: **44×44px** (iOS HIG 기준)
- 인접 버튼 간 최소 간격: 8px
- Bottom Nav 탭 아이템: 최소 60px 높이

## 7. 성능 최적화 방안

### 7.1 초기 로딩

- **코드 분할**: 라우트별 Lazy Loading (`React.lazy + Suspense`)
- 차트 컴포넌트: 화면 진입 시 로딩 (평가결과, 대시보드)
- 이미지: WebP 포맷, `loading="lazy"`

### 7.2 위젯 공개 조회 (17-위젯공개조회)

- CDN 캐시 1시간 (`Cache-Control: max-age=3600`)
- 정적 자산 `<link rel="preload">` 태그
- 최소 JS 번들 (위젯 전용 별도 번들, 앱 코어와 분리)

### 7.3 실시간 데이터 (08-평가실행 진행률)

- WebSocket 또는 SSE (Server-Sent Events)
- 연결 끊김 시 자동 재연결 (3초 후), UI 재연결 안내 배너 표시
- 폴링 대신 푸시 방식으로 불필요한 요청 제거

### 7.4 목록/테이블 성능

- 페이지네이션: 1페이지 20건 고정
- 가상 스크롤: 테스트셋 케이스 목록 (1,000건 이상)

### 7.5 차트 렌더링

- 초기: SVG 기반 정적 차트 (빠른 렌더)
- 인터랙션(호버/탭) 필요 시: Canvas 기반 전환
- 데이터 포인트 > 100개: 다운샘플링 적용
