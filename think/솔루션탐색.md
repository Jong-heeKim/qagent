## Needs Statement (방향성 재확인)

> **AI Agent 품질 측정이 필요한 사용자는 AI Agent가 얼마나 잘 작동하는지를 조직 전체가 공유된 기준으로 이해하고 함께 개선해 나가기 위하여, 역할과 기술 수준에 관계없이 품질의 의미를 즉시 파악하고 측정에서 개선까지 끊김 없이 이어지는 경험이 필요하다.**

## 아이디어 발산 결과

> 각 팀원이 전문성을 내려놓고 사용자 입장에서 발상한 아이디어입니다.

| 팀원 | 구분 | 아이디어명 | 설명 |
|------|------|-----------|------|
| **온달** (PO) | Big Idea | AI 품질 주치의 (Quality Doctor) | 측정 결과를 자연어 "처방전" 형태로 자동 생성. "이 AI는 정확도가 낮으니 검색 범위를 넓히세요"처럼 기술 지식 없이도 이해하고 행동할 수 있는 개선 처방 리포트 제공 |
| **온달** (PO) | Big Idea | 업계 품질 리더보드 | 참여 기업들의 품질 데이터를 익명 집계하여 "같은 금융 도메인 AI 중 상위 30%"처럼 실시간 업계 벤치마크 비교 제공. 경쟁 동기 부여로 품질 투자 자연스럽게 유도 |
| **온달** (PO) | Big Idea | 품질-비즈니스 연결 대시보드 | AI 품질 지표(Faithfulness, Context Recall)와 실제 비즈니스 KPI(고객 이탈률, 컴플레인 건수, 재구매율) 간 인과관계를 시각화. "품질 0.1 향상 시 컴플레인 15% 감소" 같은 ROI를 경영진 언어로 표현 |
| **온달** (PO) | Little Win | 신호등 품질 위젯 | 빨강/노랑/초록 신호등으로 AI 현재 품질 상태를 즉시 파악하는 임베드 가능한 위젯. 기술 지표 대신 "주의 필요 / 정상 / 우수" 언어로 표시하여 누구나 이해 가능 |
| **온달** (PO) | Little Win | 자동 품질 주간 브리핑 | 매주 AI 품질 현황을 비기술 언어로 자동 요약하여 팀 전체에 공유. 엔지니어 없이도 PM·팀장이 품질 상태를 주기적으로 파악하고 회의에 활용 가능 |
| **온달** (PO) | Crazy Idea | AI Agent 자율 자가치유 시스템 | 품질 저하가 감지되면 AI가 스스로 원인을 분석하고 프롬프트·파라미터를 자동 조정하여 품질을 복구. 사람의 개입 없이 AI가 자신을 치료하는 완전 자율 품질 유지 시스템 |
| **쿼리** (AI품질엔지니어) | Big Idea | 서비스 설명→자동 테스트셋 생성 AI | "우리 AI는 의료 상담 챗봇입니다"라고 입력하면 해당 도메인에 맞는 테스트 케이스(질문+정답+평가 기준)를 자동 생성. 테스트셋 구축에 수주가 걸리는 문제를 수 분으로 단축 |
| **쿼리** (AI품질엔지니어) | Big Idea | 도메인 전문가 참여 플랫폼 (Human Quality Network) | 의사·교사·금융전문가 등 도메인 전문가가 AI 응답의 적절성을 간단한 인터페이스로 평가하고, 그 피드백이 품질 지표에 자동 반영되는 크라우드소싱 품질 검증 네트워크 |
| **쿼리** (AI품질엔지니어) | Big Idea | 업계 공개 벤치마크 생성 플랫폼 | 기업들이 익명으로 품질 측정 결과를 공유하여 집계하는 개방형 벤치마크 플랫폼. 업계 표준이 없는 현재 상황에서 플랫폼이 표준 기관 역할을 자처하여 선점 효과 확보 |
| **쿼리** (AI품질엔지니어) | Little Win | 컴플레인→테스트케이스 자동 변환 | 고객 컴플레인 내용을 붙여넣으면 자동으로 테스트 케이스로 변환. "AI가 틀린 답을 줬다"는 컴플레인이 즉시 재발 방지 테스트로 전환되어 품질 이슈의 재발 차단 |
| **쿼리** (AI품질엔지니어) | Little Win | 평가 템플릿 마켓플레이스 | 금융·의료·교육·이커머스별 검증된 평가 템플릿을 제공하는 마켓플레이스. 처음 팀도 즉시 도메인에 맞는 평가 기준으로 시작 가능하여 초기 설정 장벽 제거 |
| **쿼리** (AI품질엔지니어) | Crazy Idea | AI가 AI를 평가하는 자율 평가 네트워크 | 여러 AI Agent가 서로를 교차 평가하는 탈중앙화 품질 검증 네트워크. 인간 평가자나 단일 기준 없이도 상호 검증으로 품질 기준이 자생적으로 형성되는 생태계 |
| **루나** (ML엔지니어) | Big Idea | 품질 점수 자동 번역기 (Quality Translator) | Faithfulness 0.73 같은 기술 지표를 "이 AI는 10번 중 7번 정확히 답하며, 같은 업계 평균(8.2번)보다 낮습니다"처럼 자연어로 자동 번역. 비기술 직군도 즉시 품질의 의미를 파악 |
| **루나** (ML엔지니어) | Big Idea | 품질 진단 MRI — AI 건강검진 정기보고서 | 주기적으로 AI Agent 품질 상태를 건강검진 결과지 형태로 자동 생성. 혈압·혈당처럼 각 지표를 "정상/주의/위험" 구간으로 표시하고 개선 처방까지 자동 제시하는 종합 진단 리포트 |
| **루나** (ML엔지니어) | Big Idea | 도메인 품질 레시피 북 (Quality Recipe) | "의료 AI 운영 팀입니다" 선택 시, 해당 도메인에서 반드시 측정해야 할 지표 조합·임계값·업계 벤치마크를 자동 구성. 처음 시작하는 팀도 도메인에 맞는 최적 평가 기준을 즉시 적용 |
| **루나** (ML엔지니어) | Little Win | 원클릭 품질 스냅샷 | URL 하나로 현재 AI Agent 품질 상태를 신호등+핵심 수치+업계 비교로 보여주는 공유 가능한 스냅샷 페이지. 엔지니어 없이도 슬랙·이메일로 즉시 공유 |
| **루나** (ML엔지니어) | Little Win | 이상 감지 알림봇 | 품질 지표가 임계값 이하로 하락 시 "어제 대비 Faithfulness 15% 하락, 최근 배포 이후 이상 징후 감지"처럼 슬랙·이메일로 즉시 알림. 컴플레인 전 사전 감지 |
| **루나** (ML엔지니어) | Crazy Idea | AI Agent 자율진화 시스템 | 품질 측정 결과를 바탕으로 AI Agent가 스스로 취약 영역의 테스트 케이스를 생성하고 프롬프트를 수정하며, 수정 전후 품질을 비교하여 더 나은 버전으로 자동 업그레이드하는 완전 자율 품질 개선 루프 |
| **스택** (백엔드개발자) | Big Idea | 품질 API 유니버스 (Quality API Universe) | 품질 측정 결과를 어디서나 접근 가능한 API로 제공. Slack 봇·Jira 위젯·GitHub PR 체크·경영진 대시보드·모바일 앱 등 각자가 쓰는 도구에서 품질 정보를 자동으로 수신 |
| **스택** (백엔드개발자) | Big Idea | 품질 타임머신 (Quality Time Machine) | 모든 품질 측정 결과를 타임라인으로 저장하고, "이 날 프롬프트 변경 후 Faithfulness 12% 개선"처럼 변경 이력과 품질 변화를 연결하는 이력 분석 시스템. 어떤 결정이 효과를 냈는지 추적 |
| **스택** (백엔드개발자) | Big Idea | 품질 시민권 플랫폼 (Quality Citizenship Platform) | 도메인 전문가(의사·교사·금융전문가)가 스마트폰으로 AI 응답의 적절성을 간단히 평가하는 Human-in-the-Loop 앱. 피드백이 품질 지표와 자동 연결되어 벤치마크 데이터 신뢰도 축적 |
| **스택** (백엔드개발자) | Little Win | 워크플로우 통합 품질 체크포인트 | GitHub PR·Jenkins 파이프라인 등 기존 개발 워크플로우에 품질 체크 게이트 추가. "Faithfulness < 0.8이면 배포 차단" 규칙을 코드 한 줄로 설정하여 품질 기준 이하 배포 자동 방지 |
| **스택** (백엔드개발자) | Little Win | 팀별 품질 목표 관리판 | OKR처럼 팀별 품질 목표(이번 분기 Faithfulness 0.85 달성)를 설정하고 현재 달성률·추이·필요 개선폭을 자동으로 보여주는 팀 단위 품질 관리 보드 |
| **스택** (백엔드개발자) | Crazy Idea | AI Agent 품질 NFT | 특정 품질 기준을 통과한 AI Agent에게 블록체인 기반 품질 인증 토큰 발급. 파트너사·고객이 "이 AI는 검증된 신뢰 AI"임을 즉시 확인. AI 간 API 계약 시 품질 인증이 필수 조건이 되는 세상 |
| **픽셀** (데이터분석가) | Big Idea | 품질 스토리텔러 (Quality Storyteller) | 품질 지표 변화를 "업계 하위 20%에서 상위 40%로 상승, 고객 컴플레인 30% 감소와 연결"처럼 자동으로 비즈니스 내러티브로 전환. 발표 슬라이드까지 원클릭 자동 생성 |
| **픽셀** (데이터분석가) | Big Idea | 품질 예측 수정구슬 (Quality Oracle) | 과거 품질 추이와 업계 패턴을 학습하여 "이 추세면 3개월 후 고객 이탈률 15% 증가 예측"처럼 품질 기반 비즈니스 영향을 사전 예측. 사전 예방적 품질 관리 문화 구축 |
| **픽셀** (데이터분석가) | Big Idea | 조직 품질 문화 지도 (Quality Culture Map) | 누가 품질 데이터를 얼마나 자주 보는지, 어떤 팀이 품질 개선에 기여했는지를 시각화. 품질 참여도 높은 팀·사람을 인정하는 게임화 요소로 품질 책임의 조직 전체 확산 유도 |
| **픽셀** (데이터분석가) | Little Win | 품질 가계부 (Quality Budget Tracker) | 품질 측정 투자 비용(API 비용·인력 시간)과 품질 개선으로 절감된 컴플레인 처리 비용·재작업 비용을 대응시키는 ROI 트래커. "투자 100만원으로 300만원 절감" 형태로 시각화 |
| **픽셀** (데이터분석가) | Little Win | 품질 주간 요약 뉴스레터 | 매주 AI 품질 하이라이트(최고 기록·이상 징후·개선 성과)를 기술 용어 없이 자동 요약하여 팀 전체에 이메일·슬랙으로 자동 발송. 조직 전체의 품질 공유 문화 조성 |
| **픽셀** (데이터분석가) | Crazy Idea | AI Agent 품질 세계 올림픽 | 전 세계 AI Agent가 표준화된 품질 테스트로 경쟁하는 글로벌 대회. 금융 AI 챔피언십·의료 AI 정확도 챔피언십 등으로 업계 표준 벤치마크가 자연스럽게 형성되고, 플랫폼이 공식 측정 기관으로 자리매김 |
