# 핵심 솔루션

**서비스**: AI Agent 품질 측정 플랫폼  
**선정 기준**: 우선순위 평가 매트릭스 — Big Bets + Utilities

## 판정 결과

> **No Brainers(비즈니스 영향도 높음 + 실현 가능성 높음)에 해당하는 솔루션이 없어, Big Bets와 Utilities를 핵심 솔루션으로 선정합니다.**

| 구분 | 의미 | 전략적 역할 |
|------|------|------------|
| **Big Bets** | 비즈니스 영향도 높음 · 실현 가능성 낮음 | 장기 경쟁 우위 확보를 위한 전략적 투자 |
| **Utilities** | 비즈니스 영향도 낮음 · 실현 가능성 높음 | 빠른 MVP 구현으로 초기 고객 가치 즉시 제공 |

## Big Bets — 전략적 투자 솔루션

*비즈니스 영향도 높음(B≥2) · 실현 가능성 낮음(F<2) · 장기 경쟁 우위 확보*

| 아이디어 제목 | 설명 | 비즈니스 가치 | 실현 가능성 |
|-------------|------|:------------:|:-----------:|
| **S01 AI 품질 해석 엔진**<br>*(Quality Insight Engine)* | Faithfulness 0.73 같은 기술 지표를 "이 AI는 10번 중 7번 정확히 대답하며 업계 평균보다 낮습니다"처럼 비기술 언어로 자동 번역하고, 건강검진 형태의 주기적 진단 리포트와 경영진 발표용 슬라이드까지 원클릭으로 자동 생성하는 해석 엔진. PM·기획자·운영자·경영진 모두 엔지니어 없이 품질의 의미를 즉시 파악하고 의사결정에 활용할 수 있게 되어, 킹핀 문제인 해석 생태계 부재를 직접 해결한다. | B 4표<br>만장일치<br>(온달·쿼리·루나·픽셀) | F 0표<br>기술 구현 복잡도 높음<br>(LLM 해석 정확도 확보 필요) |
| **S02 업계 익명 벤치마크 플랫폼** | 참여 기업들의 AI Agent 품질 데이터를 익명으로 집계하여 도메인별·서비스 유형별 업계 표준 벤치마크를 실시간 생성하고, "같은 금융 챗봇 중 상위 30%"처럼 맥락 있는 비교 결과를 제공하는 플랫폼. 참여 기업이 늘수록 벤치마크 정확도가 향상되는 데이터 네트워크 효과로 진입 장벽을 형성하며, 업계 표준 기관 포지셔닝으로 자기강화적 성장 구조를 만든다. | B 3표<br>(온달·루나·스택) | F 0표<br>익명화 설계·기업 참여 유도 등<br>생태계 구축 난이도 높음 |
| **S04 도메인 전문가 품질 평가 네트워크** | 의사·교사·금융전문가 등 도메인 실무 전문가들이 스마트폰 앱 또는 간단한 웹 인터페이스로 AI 응답의 적절성을 평가(적절/부적절/이유)하고, 그 피드백이 품질 지표와 자동 연결되어 벤치마크 데이터 신뢰도를 축적하는 Human-in-the-Loop 평가 네트워크. LLM-as-Judge의 도메인 맥락 이해 한계를 전문가 피드백으로 보완하며, 의료·금융 등 고위험 도메인의 평가 신뢰성 기반을 구축한다. | B 2표<br>(쿼리·루나) | F 0표<br>전문가 네트워크 구축 및<br>인센티브 설계 필요 |
| **S10 품질-비즈니스 연결 대시보드** | AI Agent 품질 지표(Faithfulness, Answer Relevancy 등)와 실제 비즈니스 KPI(고객 이탈률, 컴플레인 건수, 전환율) 간의 통계적 인과관계를 분석하고 시각화하는 대시보드. "Faithfulness 0.1 하락 시 고객 컴플레인 12% 증가"처럼 품질↔비즈니스 성과 간 구체적 상관관계를 데이터로 보여주어, 경영진의 품질 투자 의사결정과 예산 승인을 가속한다. | B 2표<br>(온달·픽셀) | F 0표<br>충분한 데이터 축적 및<br>인과관계 분석 모델 구축 필요 |

## Utilities — 빠른 가치 제공 솔루션

*비즈니스 영향도 낮음(B<2) · 실현 가능성 높음(F≥2) · MVP 및 초기 채택 가속*

| 아이디어 제목 | 설명 | 비즈니스 가치 | 실현 가능성 |
|-------------|------|:------------:|:-----------:|
| **S08 이상 감지 알림봇** | AI Agent 품질 지표를 실시간으로 모니터링하다가 설정 임계값 이하로 하락하거나 전일 대비 급격한 변화가 감지되면 Slack·이메일·Teams로 "어제 대비 Faithfulness 18% 하락, 최근 배포 이후 이상 징후 감지"처럼 맥락과 함께 즉시 알림을 발송하는 시스템. 인터뷰 10명 전원이 호소한 "컴플레인이 들어오기 전엔 품질 문제를 알 방법이 없다"는 사후 대응 구조를 사전 감지 체계로 전환한다. | B 0표<br>단독 사용 시<br>비즈니스 영향 제한적 | F 4표<br>만장일치<br>시계열 모니터링+임계값+알림 API<br>표준 기술 조합으로 빠른 구현 가능 |
| **S14 자동 품질 주간 브리핑** | 매주 월요일 오전, 지난 한 주간의 AI Agent 품질 현황을 기술 용어 없이 비즈니스 언어로 자동 요약하여 Slack·이메일로 팀 전체에 발송하는 자동화 브리핑. "지난 주 정확도는 업계 평균보다 8% 높았습니다. 화요일 일시적 주의 구간 진입 후 수요일 복구되었습니다"처럼 구성되어, PM·기획자·팀장이 엔지니어 요청 없이 매주 AI 품질 현황을 파악하고 조직의 품질 공유 문화를 자연스럽게 형성한다. | B 0표<br>조직 문화 개선 효과는 있으나<br>직접적 매출 기여 제한적 | F 3표<br>(온달·스택·픽셀)<br>cron+LLM 요약+이메일 발송<br>표준 자동화 패턴, 낮은 구현 난이도 |
| **S07 워크플로우 통합 품질 체크포인트** | GitHub Pull Request, Jenkins, GitHub Actions 등 기존 CI/CD 파이프라인에 AI 품질 평가 게이트를 삽입하여, 설정한 기준(예: Faithfulness ≥ 0.80)을 통과하지 못한 변경사항은 배포가 자동 차단되는 시스템. "이번 커밋으로 Faithfulness가 0.82→0.74로 하락, 설정 기준 미달로 배포 보류"처럼 구체적 사유와 함께 알림이 전송된다. YAML 설정 몇 줄로 도입 가능하며 개발팀의 품질 내재화 문화를 조성한다. | B 0표<br>개발팀 내부 효율화 효과,<br>외부 비즈니스 영향 간접적 | F 2표<br>(루나·스택)<br>기존 CI/CD 표준 패턴에<br>평가 API 연동만 추가하면 구현 |
| **S13 실시간 품질 위젯 & 스냅샷 공유** | AI Agent 현재 품질 상태를 빨강/노랑/초록 신호등과 핵심 수치, 업계 대비 위치로 보여주는 경량 위젯(기존 Notion·Slack에 임베드 가능)과, 이 정보를 URL 하나로 즉시 공유할 수 있는 스냅샷 기능이 결합된 시각화 도구. 기술 지표 대신 "주의 필요/정상/우수"와 "업계 상위 35%" 언어로 표현하여 어느 직군도 즉시 이해할 수 있으며, 경영진·파트너사에게 품질 상태를 링크 하나로 공유할 수 있다. | B 0표<br>진입 장벽 낮춰 채택률 높이지만<br>독립적 비즈니스 가치 제한적 | F 2표<br>(온달·스택)<br>기존 측정 결과의 시각화 레이어,<br>iframe+URL 방식 즉시 구현 가능 |

## 전략적 로드맵 제언

```
Phase 1 (MVP)          Phase 2 (성장)         Phase 3 (확장)
────────────────       ────────────────       ────────────────
Utilities 우선          Big Bets 착수           No Brainers 지향
빠른 고객 가치          장기 경쟁 우위           양 축 모두 강한
S08 이상 감지           S01 해석 엔진            솔루션 완성
S14 주간 브리핑         S02 벤치마크
S07 CI/CD 체크          S04 전문가 네트워크
S13 위젯 공유           S10 비즈니스 연결
```

> **핵심 관점**: Big Bets는 구현 난이도가 높지만 비즈니스 핵심 가치를 담고 있고,  
> Utilities는 즉각 구현 가능하여 초기 고객 채택을 이끈다.  
> 두 영역을 병렬로 추진하여 **단기 가치(Utilities) + 장기 경쟁력(Big Bets)**를 동시에 확보한다.
