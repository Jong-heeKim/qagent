개발 작업 순서를 터미널에 표시합니다.

```
개발 작업 순서

1단계: 데이터베이스 설치계획서 작성
/develop-db-guide
- 데이터베이스설치계획서가이드에 따라 설치계획서를 작성합니다
- [설치정보] 섹션에 설치대상환경과 NAMESPACE를 제공합니다

2단계: 데이터베이스 설치
/develop-db-install
- 데이터베이스설치가이드에 따라 설치합니다
- [설치정보] 섹션에 설치에 필요한 정보를 제공합니다

3단계: 데이터베이스 제거 (필요시)
/develop-db-remove
- 데이터베이스 관련 모든 리소스를 삭제합니다

4단계: Message Queue 설치계획서 작성 (필요시)
/develop-mq-guide
- MQ설치게획서가이드에 따라 설치계획서를 작성합니다

5단계: Message Queue 설치 (필요시)
/develop-mq-install
- MQ설치가이드에 따라 설치합니다
- [설치정보] 섹션에 설치에 필요한 정보를 제공합니다

6단계: Message Queue 제거 (필요시)
/develop-mq-remove
- MQ 관련 모든 리소스를 삭제합니다

7단계: 백엔드 개발
/develop-dev-backend
- 백엔드개발가이드에 따라 개발합니다
- [개발정보] 섹션에 서비스별 아키텍처패턴을 제공합니다

8단계: 백엔드 오류 해결 (필요시)
/develop-fix-backend
- 각 서비스를 컴파일하고 에러를 해결합니다

9단계: 서비스 실행파일 작성
/develop-make-run-profile
- 서비스실행파일작성가이드에 따라 실행프로파일을 작성합니다
- [작성정보] 섹션에 API Key 정보를 제공합니다

10단계: 백엔드 테스트
/develop-test-backend
- 백엔드테스트가이드에 따라 테스트합니다
- [테스트정보] 섹션에 서비스명과 API Key를 제공합니다

11단계: 백엔드 테스트 코드 개발 (필요시)
/develop-dev-backend-testcode
- 백엔드테스트코드작성가이드에 따라 테스트 코드를 작성합니다
- [개발정보] 섹션에 서비스명, 테스트유형, 테스트대상을 제공합니다

12단계: 프론트엔드 개발
/develop-dev-front
- 프론트엔드개발가이드에 따라 개발합니다
- [개발정보] 섹션에 개발 프레임워크 정보를 제공합니다
```
